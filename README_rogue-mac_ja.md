# Rogue for macOS（rogue-mac）

AppleScriptによるGUI版「Rogue for macOS」に対応した、ターミナル用ランチャーです。Rogue 5.4、Clone III、DOS Tribute、3.6、5.2の5種類に対応します。

GUI版と同じセーブ・スコアファイルの保存先を使用し、プレイヤー名、好きな果物、最後に選択したバージョン、バージョン別のゲーム設定を共有します。すべての設定はmacOS標準の共有領域 `com.leopard.rogue` に保存します。AppleScript版に同じ項目がある場合は必ずその既存設定を使用し、CUI独自の上書き設定は作りません。AppleScriptにない追加項目も同じ共有領域の新しいキーへ保存します。手動で管理する設定ファイルは作りません。

## 起動方法

```sh
rogue-mac           # メニューから選択
rogue-mac 54        # Rogue 5.4
rogue-mac clone     # Rogue Clone III
rogue-mac dos       # Rogue DOS Tribute
rogue-mac 36        # Rogue 3.6
rogue-mac 52        # Rogue 5.2
rogue-mac 54 -s     # 実行ファイルに引数を直接渡す
rogue-mac --help
```

起動時には「やあ、（プレイヤー名）。運命の洞窟へようこそ・・・」と挨拶し、好きな果物と5種類のバージョンを表示します。標準のセーブファイルが見つかると「セーブあり」を表示します。

メインメニューの操作は次のとおりです。入力後にReturnで確定します。

| 入力 | 動作 |
| --- | --- |
| `1`〜`5` | 冒険するバージョンを選択 |
| Returnのみ | 前回選択したバージョンを選択 |
| `P` | プレイヤー情報の設定 |
| `G` | 「【運命の洞窟】への案内書」をWebで開く |
| `S` | ゲーム設定 |
| `Q` | ランチャーを終了 |

入力欄には「冒険したいバージョンまたは操作を選ぶ」と表示されます。Returnの案内は「Return：前回選択した Rogue 3.6 を起動」のように実際のバージョン名を示します。選択履歴はAppleScriptと共通の `Savedmygameversion` に保存します。GUI版では画面でバージョンを選んだ時点でも更新されるため、厳密には「最後に実際にゲームを開始したバージョン」ではありません。CUI版の対応外の値が保存されている場合は5.4を既定とします。

`Q` で終了したときや、ゲーム後に `N` で終了したときは、AppleScriptと同じ「それでは、またね。」（英語表示では `See you again.`）を、画面を消去してから表示します。

通常のカラーメニューは、Terminalの背景設定に関係なく画面全体を黒背景で描画します。`--mono` を指定したときは従来どおり端末の既定色を使用します。ゲームの起動前と終了時の挨拶前には、端末の通常の色と背景に戻します。
## 案内書の閲覧

メインメニューで `G` を入力すると「【運命の洞窟】への案内書」の選択画面になります。`1`〜`5` で閲覧したいバージョンを選ぶと、macOSの標準ブラウザで対応するWeb案内書を開き、ランチャーはメインメニューに戻ります。

Returnのみで**前回選択したバージョン**の案内書を開きます。`B` で閲覧せずにメインメニューへ戻れます。

案内書の閲覧によって、GUI版と共有する「前回選択したバージョン」やゲーム設定は変更されません。Web版の閲覧にはインターネット接続が必要です。

## セーブ・再プレイ

標準セーブがない場合は新規ゲームを起動します。ある場合は以下を選択します。

| 入力 | 動作 |
| --- | --- |
| `R` またはReturn | 標準セーブから再開 |
| `N` | 新しい冒険を始める（以前のセーブを削除しない） |
| `F` | 別のセーブファイルをパスで指定 |
| `Q` | バージョン選択に戻る |

ゲーム終了後は画面全体を黒背景で消去し、`Y`（同じバージョンでもう一度）、`M`（メインメニューへ戻る）、`N`（終了）を選びます。終了の挨拶は端末の通常の文字色で表示します。`Y` を選ぶたびに標準セーブの有無を確認します。3.6と5.2では終了画面を確認できるようにReturn待ちを入れます。

## プレイヤー情報（GUI版と共通）

メインメニューから `P` を選択します。

| 入力 | 動作 |
| --- | --- |
| `1` | プレイヤー名を変更 |
| `2` | 好きな果物を変更 |
| `3` | 名前をmacOSユーザーのフルネームへ戻す |
| `4` | 果物を言語に応じた初期値へ戻す |
| `B` | メインメニューへ戻る |

文字列入力欄はUTF-8対応の編集方式を使用します。日本語や絵文字のBackspace、左右矢印によるカーソル移動、Delete、Home／End、Control-A／Control-E、Control-Uによる入力行消去に対応します。Escまたは空欄のReturnで変更をキャンセルできます。

共有するキーは `Savedmyname` と `Savedmyfruit` です。未設定のプレイヤー名はmacOSのフルネーム（取得できなければログイン名）を使用します。果物の初期値は日本語で「ネバネバかび」、英語で `slime-mold` です。名前・果物には日本語、通常の絵文字、空白が使えますが、`ROGUEOPTS` の区切り文字であるカンマと改行は指定できません。空欄での変更入力はキャンセルです。

## ゲーム設定（GUI版と共通）

メインメニューから `S` を選択します。選択中のバージョンの「モード」「表示言語」と、そのゲームが対応する設定項目を表示します。

| バージョン | 個別に変更できる項目 |
| --- | --- |
| 5.4 | カラー表示、識別の巻物、表示の長さ、曲がり角 |
| Clone III | カラー表示、曲がり角、ジャンプ |
| DOS Tribute | カラー表示、マップ文字、キー操作、マクロ、表示の長さ |
| 3.6 | 表示の長さ、ジャンプ、未識別品の確認 |
| 5.2 | カラー表示、曲がり角、表示の長さ、未識別品の確認 |

`jump` と `askme` は保存時にはGUI版と互換の `True`／`False` を使用しますが、日本語の設定画面では「有効／無効」と表示します（英語画面は `True`／`False`）。

設定画面では数字で個別項目を変更でき、`M` でモード（モダン／クラシック／細かく設定）、`L` で言語（日本語／English）、`A` ですべてのオプション設定、`V` で設定対象のバージョンを切り替え、`B` で戻ります。個別項目を変更すると、GUI版と同様にモードは「細かく設定」になります。モダン／クラシックを選択した場合は、GUI版のモード別プリセットを適用します。

設定は `SavedVersion54_*`、`SavedVersionCloneIII_*`、`SavedVersionDOS148_*`、`SavedVersion36_*`、`SavedVersion52_*` の各キーへ保存します。`3.6`・`5.2` の `askme` / `noaskme` は、修正後のAppleScriptと同様に、起動する時点のモード・設定から生成します。モダンでは有効、クラシックでは無効、「細かく設定」では個別の値に従います。

AppleScriptの初期値に合わせて、DOS Tributeで「5.4風」を選んだ場合は `nodoskeys` を指定し、「DOS 1.48風」ではゲーム本体の既定 `doskeys` を使います。マクロも共通設定を使います。5.2のジャンプは通常はAppleScriptと同様に `nojump` を指定しますが、「細かく設定」でジャンプを有効にした場合は `jump` を指定します。

**新規ゲーム**では、設定から生成した `ROGUEOPTS` を使います。ログインシェルで指定されたオプションのうち、AppleScriptと共通の項目にはランチャーで選択した値を優先し、残りの対応項目は引き継ぎます。**セーブ再開**では基本的に言語指定だけを渡して、ゲーム保存時の内容を優先します。ゲームの引数を明示して起動した場合は、引数をそのまま渡し、環境変数には取得したログインシェルの `ROGUEOPTS` を使用します。

GUI版とCUI版を同時に起動して設定変更すると、一方の読み込み済みの古い値で上書きされる可能性があります。変更後はもう一方を起動し直してください。また、設定画面の表示だけでは共有設定を書き換えません。

## ログインシェルの `ROGUEOPTS` を取得

AppleScript版と同様に、macOSのユーザーアカウントに登録されたログインシェルを対話型ログインモード（`-lic`）で起動し、その初期化ファイルで設定された `ROGUEOPTS` を取得します。**親プロセスから継承した古い `ROGUEOPTS` や `launchctl` の値を代わりに使用することはありません。** 取得用シェルはユーザーの端末から切り離して起動するため、端末入力の取り合いによる停止を防ぎます。シェルの起動時メッセージは読み飛ばし、初期化が5秒以内に完了しない場合や取得できない場合は、外部指定を使用せずに続行します。

ランチャー起動時は、取得した `color`・`passgo`・`language`・`name`・`fruit` など、AppleScript版と共通の項目を画面の初期値に反映します。同じ起動中にランチャーの設定画面から変更した項目は、その変更を優先します。**ゲーム起動直前にもログインシェルから再取得**し、共通設定で管理していない追加オプションを新規ゲームへ渡します。`file=` はランチャーの標準セーブ判定と衝突するため、外部指定からは引き継ぎません。

この取り込み処理は共有設定を無断で保存・変更しません。ログインシェルの取得用プロセスは、確実に別セッションへ移行できるよう子プロセスを生成してから切り離します。

**取得結果の確認：** `rogue-mac --show-rogueopts` で、ログインシェルから取得できた `ROGUEOPTS` の値を表示できます。値が空の場合は未設定と取得失敗を区別できないため、必要に応じてシェルの初期化ファイルも確認してください。

**新規ゲームでの追加項目の優先順位：** 全オプション画面で明示的に選んだ値 → ログインシェルで指定した値 → ゲーム本体の既定値。共通項目は従来どおりGUIとの共有設定を使い、同じ起動中の利用者による変更を優先します。外部 `file=` の指定は従来どおり除外します。

## 全オプションの設定

ゲーム設定（`S`）から `A` を押すと、選択中のバージョンに対応するすべての `ROGUEOPTS` 項目が、現在の設定値とともに一覧表示されます。画面では設定の保存方法による分類を表示せず、項目番号を選ぶだけで変更できます。**AppleScriptにも存在する項目は、従来の共有設定の値をそのまま表示・変更します。** `color` や `passgo`、`name`、`fruit`、`language` などにCUI専用の上書き設定は設けません。共通項目を変更するとGUI版からも新しい値が参照されます（モード・言語・プリセット処理は通常のゲーム設定と同じです）。

AppleScriptの設定項目にない `flush`、`step`、`inven`、`menu` などは追加項目として扱い、**同じ `com.leopard.rogue` 領域の新しいキー**に保存します。追加項目が未設定の場合は、ログインシェルに指定があればその値を表示し、なければHomebrew標準ビルドでのデフォルト値（「有効」「無効」など）を表示します。設定の選択画面では、ゲーム本体のデフォルトの選択肢に「（デフォルト）」を付けます。**「（デフォルト）」を明示的に選んだ場合もその値を保存する**ので、ログインシェルに反対の指定があっても選択した値を優先します。CUI専用の設定領域 `com.leopard.rogue.cui` は使用しません。

| バージョン | 全オプション画面で扱える項目 |
| --- | --- |
| 5.4 | `color`, `cursor`, `seefloor`, `terse`, `flush`, `jump`, `passgo`, `tombstone`, `inven`, `idscrl`, `name`, `fruit`, `language`, `file` |
| Clone III | `color`, `cursor`, `jump`, `passgo`, `noaskquit`, `noskull`, `name`, `fruit`, `language`, `file` |
| DOS Tribute | `color`, `cursor`, `extchars`, `terse`, `jump`, `doskeys`, `menu`, `macro`, `name`, `fruit`, `language`, `file` |
| 3.6 | `terse`, `flush`, `jump`, `step`, `askme`, `name`, `fruit`, `language`, `file` |
| 5.2 | `color`, `cursor`, `terse`, `flush`, `jump`, `step`, `askme`, `passgo`, `name`, `fruit`, `language`, `file` |

追加項目では、有効／無効、選択式、文字列入力に対応します。AppleScript側に「カラー／モノクロ」「１種類／５種類」「短くする／ふつう」「止まらない／止まる」「拡張／基本」「5.4風／DOS 1.48風」といった選択肢がある項目は、全オプション画面でも同じ表現を使用します。`jump` と `askme` は「有効／無効」で表示します。Clone IIIの `noaskquit`・`noskull` なども、操作上は有効／無効の両方を表示します。有効を選んだ場合、ゲーム側に有効化トークンがない項目は外部の無効指定を取り除いて既定動作に戻します。5.4の `inven` は上書き・低速・クリア、DOS Tributeの `menu` は `on`・`sel`・`off` の選択式です。文字列入力ではカンマ・制御文字・不正なUTF-8などを検査します。DOS Tributeのマクロは本体に合わせて最大40バイトとし、ゲーム側で除去される再帰呼び出しキー `x` は入力できません。各オプションの選択画面には「現在の設定：」を表示します。入力欄の「空欄でキャンセル」のとおり、空欄でReturnを押すと変更をキャンセルできます。文字列入力では日本語・絵文字を1文字（結合文字を含む表示単位）ごとに削除でき、左右カーソルキーで入力位置を移動できます。`Home`／`End`・`Delete`・`Control-A`／`Control-E` にも対応します。`Control-U` ですべて消去してReturnを押すか、`Esc` を押すと入力をキャンセルできます。数字やメニュー文字の選択操作は従来どおりです。`file` の既定値は各ゲームの標準セーブファイル名です。

`R` は「**個別設定をリセット**」、`B` は通常のゲーム設定画面へ戻る操作です。リセット前に確認画面を表示し、このバージョンで個別に保存したオプション指定だけを解除します。プレイヤー名・果物・カラーなどの基本設定は維持します。解除後はログインシェルの `ROGUEOPTS` に値があればそれを使用し、なければゲーム本体の初期値を使用します。`N` またはReturnではリセットしません。

画面の「デフォルト」は各ゲームのHomebrew標準ビルドでの値です。AppleScript側のモダン／クラシックのプリセットや、ログインシェルで指定した `ROGUEOPTS` の現在値とは異なる場合があります。

**起動時への適用：** 追加項目の保存値も新規ゲームの `ROGUEOPTS` へ反映されます。5.4の `inven` は言語を先に指定し、詳細画面の設定値だけでなく、ログインシェルの `inven=Slow` なども、実際の表示言語に合う名称へ変換して渡します。詳細設定で指定した `file=` は標準セーブの検出と再開の対象にも反映します（外部 `file=` は除外）。セーブ再開時の言語のみを渡す方針、明示的な引数で起動した際にログインシェルの値を渡す方針は従来どおりです。

追加項目のキーは `SavedVersion54_rogueopt_flush`、`SavedVersionCloneIII_rogueopt_noskull`、`SavedVersionDOS148_rogueopt_menu`、`SavedVersion36_rogueopt_step` などです。以前の試作版0.3.4で `com.leopard.rogue.cui` に保存した値は自動移行・削除せず、以後の起動にも使用しません。

## GUI版と共通の保存先

`~/Library/Application Support/Rogue/` 以下を使用します。

| バージョン | フォルダ | 標準セーブファイル |
| --- | --- | --- |
| 5.4 | `5.4/` | `rogue.save` |
| Clone III | `Clone III/` | `rogue-clone.save` |
| DOS Tribute | `DOS 1.48/` | `rogue-dos.save` |
| 3.6 | `3.6/` | `rogue36.save` |
| 5.2 | `5.2/` | `rogue52.save` |

セーブファイルの形式や再開後のファイルの扱いはゲーム本体に任せます。ランチャーは保存ファイルの移動・変換・削除を行いません。GUI版とCUI版で同じセーブデータを同時に操作しないでください。

別のセーブファイルは絶対パス、`~/` から始まるパス、または選択バージョンの保存先からの相対パスで指定できます。全オプション画面から `file=...` を変更した場合は、セーブ検出にも同じファイル名を使用します。ログインシェルにある外部 `file=` は引き継がず、標準セーブ検出を優先します。
