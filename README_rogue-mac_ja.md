# Rogue for macOS（rogue-mac）

Rogueの異なるバージョンや派生版（5.4、Clone III、DOS Tribute、3.6、5.2、3.4）をターミナルから選べる、**Rogue for macOSのCUI版**ランチャーです。[GUI版「Rogue for macOS」](https://leopard-gecko.github.io/jrogue/)とプレイヤー情報、ゲーム設定、セーブ・スコアファイルを共有します。

## 起動方法

```sh
rogue-mac           # メニューを開く
rogue-mac 54        # Rogue 5.4
rogue-mac clone     # Rogue Clone III
rogue-mac dos       # Rogue DOS Tribute
rogue-mac 36        # Rogue 3.6
rogue-mac 52        # Rogue 5.2
rogue-mac 34        # Rogue 3.4
rogue-mac --help    # 使い方を表示
```

メニューでは番号やアルファベットを入力し、Returnで確定します。

| 入力 | 動作 |
| --- | --- |
| `1`〜`6` | 遊びたいバージョンを選ぶ |
| Returnのみ | 前回選択したバージョンを選ぶ |
| `P` | プレイヤー情報を変更 |
| `G` | 案内書を開く |
| `S` | ゲーム設定を変更 |
| `Q` | 終了 |

メニューの背景にはTerminalの現在の設定を使います。文字色も端末標準のものにしたい場合は `rogue-mac --mono` で起動してください。

## 案内書の閲覧

メインメニューで `G` を選び、`1`〜`6` でバージョンを指定すると、Webブラウザで案内書が開きます。Returnのみなら前回選択したバージョン、`B` ならメインメニューに戻ります。閲覧にはインターネット接続が必要です。

## セーブ・再プレイ

セーブファイルがある場合は、開始前に次の操作を選べます。

| 入力 | 動作 |
| --- | --- |
| `R` またはReturn | セーブから再開 |
| `N` | 新しい冒険を始める |
| `F` | 別のセーブファイルを選ぶ |
| `Q` | バージョン選択に戻る |

セーブがない場合は新規ゲームを始めます。

ゲーム終了後は `Y` でもう一度、`M` でメインメニュー、`N` で終了します。

## プレイヤー情報（[GUI版](https://leopard-gecko.github.io/jrogue/)と共通）

メインメニューで `P` を選びます。

| 入力 | 動作 |
| --- | --- |
| `1` | プレイヤー名を変更 |
| `2` | 好きな果物を変更 |
| `3` | 名前をMacのユーザー名に戻す |
| `4` | 果物を初期値に戻す |
| `B` | メインメニューへ戻る |

日本語や一般的な絵文字も入力できます。空欄のままReturnを押すと変更をキャンセルします。名前や果物にはカンマと改行を使用できません。

## ゲーム設定（[GUI版](https://leopard-gecko.github.io/jrogue/)と共通）

メインメニューで `S` を選びます。**モダン／クラシック**では設定をまとめて切り替え、**細かく設定**では項目ごとに変更できます。変更できる項目はバージョンによって異なります。

| バージョン | 主な設定項目 |
| --- | --- |
| 5.4 | カラー表示、識別の巻物、表示の長さ、曲がり角 |
| Clone III | カラー表示、曲がり角、ジャンプ |
| DOS Tribute | カラー表示、マップ文字、キー操作、マクロ、表示の長さ |
| 3.6 | 表示の長さ、ジャンプ、未識別品の確認 |
| 5.2 | カラー表示、曲がり角、表示の長さ、未識別品の確認 |
| 3.4 | 表示の長さ、ジャンプ、未識別品の確認 |

設定画面の操作は次のとおりです。

| 入力 | 動作 |
| --- | --- |
| 数字 | 表示されている項目を変更 |
| `M` | モードを変更 |
| `L` | 表示言語を変更 |
| `A` | 詳細設定を開く |
| `V` | 設定するバージョンを変更 |
| `B` | メインメニューへ戻る |

個別の項目を変更すると「細かく設定」に切り替わります。[GUI版](https://leopard-gecko.github.io/jrogue/)で変更した設定も反映されます。

## 詳細設定

ゲーム設定で `A` を選ぶと、通常の設定画面にない項目も変更できます。**数字**で項目を選び、`B` でゲーム設定へ戻ります。

| バージョン | 主な追加項目 |
| --- | --- |
| 5.4 | カーソル、照明範囲の床表示、戦闘時の入力、移動中の表示、墓標、持ち物の表示方式 |
| Clone III | カーソル、終了時の確認、死亡時の骸骨表示 |
| DOS Tribute | カーソル、移動中の表示、持ち物メニュー |
| 3.6 | 戦闘時の入力、持ち物の段階表示 |
| 5.2 | カーソル、戦闘時の入力、移動中の表示、持ち物の段階表示 |
| 3.4 | 戦闘時の入力、持ち物の段階表示 |

多くの項目は「有効／無効」で切り替えます。セーブファイル名の変更もこの画面から行えます。

`R` を選ぶと、**そのバージョンの追加設定をまとめてリセット**できます。プレイヤー名や通常のゲーム設定は変更されません。

## 環境変数ROGUEOPTSの取り込み

`ROGUEOPTS` は、Rogueの表示や操作をゲーム起動前に指定するための環境変数です。例えば `language=ja` は日本語表示、`color` はカラー表示を指定します。複数の設定はカンマで区切ります（利用できる項目はバージョンによって異なります）。

CUI版ランチャーは、**Macのログインシェルに設定されている `ROGUEOPTS` を取り込み**、ゲーム起動時の設定に反映します。ランチャーで変更した設定が優先されます。セーブから再開する場合は、保存済みのゲーム設定を優先します。

Mac標準のzshでは、`~/.zshrc` に次の1行を追加すると、Rogueの起動時に設定が適用されます。`~/.zprofile` に記載しても利用できます。

```sh
export ROGUEOPTS="language=ja,color"
```

ターミナルを開き直した後、次のコマンドで取り込まれる内容を確認できます。

```sh
rogue-mac --show-rogueopts
```

通常はランチャーの `S`（ゲーム設定）から変更できるため、`ROGUEOPTS` を自分で設定する必要はありません。

## [GUI版](https://leopard-gecko.github.io/jrogue/)と共通の保存先

セーブファイルは `~/Library/Application Support/Rogue/` 以下に保存されます。

| バージョン | フォルダ | 標準セーブファイル |
| --- | --- | --- |
| 5.4 | `5.4/` | `rogue.save` |
| Clone III | `Clone III/` | `rogue-clone.save` |
| DOS Tribute | `DOS 1.48/` | `rogue-dos.save` |
| 3.6 | `3.6/` | `rogue36.save` |
| 5.2 | `5.2/` | `rogue52.save` |
| 3.4 | `3.4/` | `rogue34.save` |

別のセーブファイルは、再開時に `F` で指定できます。標準のセーブファイル名を変更する場合は「詳細設定」を利用してください。

[GUI版](https://leopard-gecko.github.io/jrogue/)とCUI版はセーブファイルを共用しており、一方でセーブした冒険をもう一方から再開できます。

### 3.4・3.6の端末表示

「ゲーム設定」（S）でRogue 3.4／3.6を選ぶと、「端末表示」で「通常・白色モノクロ・緑色モノクロ・アンバー」を選べます。白色は**P4蛍光体**、緑色は**P31蛍光体**、アンバーは**橙色系の蛍光体**を参考に、当時のモノクロ端末の色合いを再現しています。

設定はGUI版とCUI版で共有され、3.4と3.6それぞれに保存されます。macOS標準のTerminal.appで一時的に表示色を変更し、ゲーム終了後のReturn操作が終わると元に戻ります。新しいTerminalプロファイルは作成しません。
